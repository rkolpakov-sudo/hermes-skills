# PDF без текстового слоя → последовательный vision

Когда применять: `page.get_text()` пустой на страницах с таблицами/текстом (векторные кривые, скан), а tesseract-OCR непригоден. Рабочий метод — **последовательный** `vision_analyze` по рендерам страниц + tight-crop верификация подозрительных токенов.

## Пайплайн (строго)
1. **Рендер**: каждая страница @200 DPI → downscale width=1600px (полные страницы таймаутят на локальных моделях). Все оставшиеся страницы pre-downscale одним batch-проходом.
```python
import pymupdf
from PIL import Image
doc = pymupdf.open(pdf)
page = doc[N-1]  # 0-based
pix = page.get_pixmap(matrix=pymupdf.Matrix(200/72, 200/72))
img = Image.frombytes("RGB", (pix.width, pix.height), pix.samples)
w, h = img.size
if w > 1600: img = img.resize((1600, int(h*1600/w)), Image.LANCZOS)
img.save(f'p{N}_sm.png')
```
2. **Чтение**: `vision_analyze` на p{N}_sm.png → структурированный ответ (для таблиц — JSON-массив строк, пустые ячейки = "", порядок сверху вниз). НЕМЕДЛЕННО после чтения — сохранить в per-page файл (`data/p{N}.json`) как checkpoint: сессия может прерваться в любой момент.
3. **Верификация** подозрительных токенов (см. ниже) → tight crop.
4. **Batch-fix артефактов** по всем per-page файлам одним проходом (см. каталог).
5. **Агрегация** per-page файлов → финальная структура → build/отчёт → анализ → уведомление.

## Правила чтения
- ТОЛЬКО последовательное чтение. Параллельные субагенты на локальной LM Studio — все timeout 600s; не повторять.
- Подозрительный токен (код, число, примечание) → tight crop: `clip=Rect(...)`, `matrix=Matrix(5,5)`, downscale ≤1200px → «прочитай дословно».
- Зум <3x галлюцинирует (читает мусор как текст) — не доверять, переснимать 4–5x. Сверх-узкий кроп при низком эффективном разрешении тоже читается как мусор — брать ячейку целиком.
- Кроп таймаутит → уменьшать ширину (1600→1200→900), НЕ зум.
- Кросс-проверка кодов/марок по другим документам проекта С ТЕКСТОВЫМ СЛОЕМ — легитимный контроль извлечения, не поиск логики.

## Систематические misread'ы vision (каталог)
- **Потеря «1»**: EI50 вместо EI150; L=21720→2120. Верифицировать tight crop'ом высокого зума.
- **FPV-(I20)** → реально (120). FPV-коды бывают только (60)/(120).
- **Кириллическая Е / латинская E вместо EI**: «Е160»=EI60, «E(90)»=EI90.
- **Классы фильтров** в курсивном шрифте: G4 (грубая) + F7 (тонкая) — стандартная ISO-пара; неоднозначность глифы (E6/EG/EВ → G4, EF.7/E7.7 → F7).

## Смешанные скриптовые артефакты (batch-fix)
Regex-скан `[А-Яа-яЁё][A-Za-z]` по ВСЕМ per-page файлам: КVK→КВК, Изоvent/Изовент→Изоверт, Оgneзащитное→Огнезащитное. Исправлять скриптом одним проходом по всем файлам.

## Дословная транскрипция (директива пользователя)
Не искать логику в документе — в нём могут быть ошибки проектировщика. Арифметическая верификация внутренних расчётов ЗАПРЕЩЕНА («Должен быть только контроль правильного извлечения!»). Транскрибировать буквально то, что напечатано (даже пустые qty-ячейки и нестыкующиеся сечения). Нестыковки — флаг в финальный отчёт для человека.
