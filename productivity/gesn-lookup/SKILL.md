# ГЭСН-lookup: работа с cs.smetnoedelo.ru

Поиск, извлечение и парсинг сметных нормативов ФСНБ-2022 (ГЭСН) для автоматизированного расчёта стоимости MEP-работ.

## Когда использовать

- Нужен состав ресурсов (труд, материалы, механизмы) по номеру расценки ГЭСН
- Нужно найти подходящую норму для конкретного вида работ по описанию
- Нужны актуальные базовые цены на материалы (ФССЦ/ФСБЦ)
- Требуется проверить наличие нормы в ФСНБ-2022

## Структура сайта cs.smetnoedelo.ru

### Основные разделы

```
cs.smetnoedelo.ru/gesn2/         — каталог ГЭСН-2022 (все сборники)
  /gesn2/sbor-{NN}/              — конкретный сборник
    /gesn2/{NN}-razd-{N}/        — раздел внутри сборника
      /gesn2/tabl-{NN}-{N}-{NNN}/ — таблица расценок

/gesn2/gesn{code}.html           — страница отдельной расценки (детальный состав)
/fsscm/                           — ФССЦ на материалы 2001
/fsbcm/                           — ФСБЦ на материалы 2022
```

## Структура страницы расценки

URL: `/gesn2/gesn{code}.html` (например, `/gesn2/gesn16-04-005-02.html`)

### Шапка страницы
- Заголовок H1: "ГЭСН {код}. {наименование}"
- Хлебные крошки: ГЭСН → Сборник → Раздел → Таблица → Расценка

### Таблица состава расценки (основная)

| Столбец | Описание | Пример |
|---------|----------|--------|
| Шифр | Код ресурса в классификаторе | 01.2.001 |
| Наименование работ, материалов и механизмов | Текстовое описание | Трубы стальные электросварные... |
| Ед. изм. | Единица измерения | м, шт., т, чел.-ч |
| Расход | Нормативный расход на единицу измерения ресурса работы | 100,0 |
| Цена за ед. | Базовая цена за единицу | 45,67 руб. |
| Сумма | Расход × Цена за ед. | 4567,00 руб. |

### Структура ресурсов в составе расценки

```
1. Затраты труда (обязательные)
   - Затраты труда рабочих (чел.-ч)       → код: {NN}-100-01 или "Затраты труда рабочих"
   - Затраты труда машинистов (маш.-ч)    → код: {NN}-200-01 или "Затраты труда машинистов"

2. Материалы (определённые + неопределённые)
   - Определённые материалы с конкретными кодами ФССЦ
   - Неопределённые материалы (в агрегированном виде)

3. Машины и механизмы
   - Конкретные машины с кодами ФСЭМ
```

```

Примеры:
  ГЭСН 16-04-005-02 — полипропилен d=25мм
  ГЭСН 16-01-001-03 — стальная черная труба d=32мм
```

## Методология поиска нормы для MEP-объекта

### Шаг 1: Определить вид работы и систему
- Водоснабжение → Сборник 16
- Отопление → Сборник 18 (или 16, если трубы общие)
- Канализация → Сборник 16
- Вентиляция → Сборник 20

### Шаг 2: Определить материал трубопровода/конструкции
- Сталь черная → Раздел 1
- Сталь оцинкованная → Раздел 2
- Медь → Раздел 3
- Пластик (ППР, ПЭ, PEX) → Раздел 4

### Шаг 3: Найти таблицу по типу работ
На странице раздела (`/gesn2/{NN}-razd-{N}/`) список таблиц с описаниями.

### Шаг 4: Выбрать расценку по диаметру
На странице таблицы (`/gesn2/tabl-{code}/`) — таблица расценок с вариантами по диаметрам.

### Шаг 5: Извлечь состав ресурсов
На странице расценки (`/gesn2/gesn{code}.html`) — полный состав с ценами.

## Парсинг страниц

### Инструмент: `mcp_windows_mcp_Scrape`

```python
# Получить таблицу расценок
scrape(url="https://cs.smetnoedelo.ru/gesn2/tabl-16-04-005/",
       query="Таблица расценок для прокладки трубопроводов")

# Получить детальную расценку
scrape(url="https://cs.smetnoedelo.ru/gesn2/gesn16-04-005-02.html",
       query="Состав расценки: затраты труда, материалы, механизмы")
```

### Паттерны для извлечения данных

**Из таблицы на странице расценки:**
- Ищем `<table>` с классом, содержащим "cost" или "estimate"
- Строки ресурсов: `<tr>` с колонками [шифр, наименование, ед.изм., расход, цена, сумма]
- Числа в формате: `13,71` (запятая = десятичный разделитель)
- Цены в формате: `45,67 руб.` или без единицы

**Из хлебных крошек:**
- Путь к расценке: ГЭСН → Сборник {N} → Раздел {N} → Таблица {NNNN} → Расценка

## Коэффициенты и пересчёт

### Пересчёт норм на фактический объём

```python
# Нормы ГЭСН даны на определённую единицу измерения (100м, 10шт., 1т и т.д.)
# Формула пересчёта:

фактическая_норма = норма_из_расценки * (фактический_объём / базовый_объём)

# Пример: труба d25, протяжённость 15.7м, норма на 100м
labor_hours = 13.18 * (15.7 / 100) = 2.07 чел.-ч
```

### Коэффициенты из технической части

- К1.1 — работы в стеснённых условиях
- К1.2 — высота работ над уровнем пола >6м
- К1.3 — работы с применением специализированной техники
- Применяются к затратам труда согласно МДС 81-35.2024

## Типичные ошибки и подводные камни

1. **Запятая vs точка**: на сайте числа с запятой (13,71), в Python — с точкой. Преобразовать перед парсингом.
2. **Базовый объём**: всегда проверяйте, на что дана норма (100м, 10шт., 1т). Пересчёт обязателен.
3. **Актуальность ФСНБ**: проверяйте дату обновления. В июле 2026 актуально дополнение №18 от мая 2026.
4. **Неопределённые материалы**: в составе расценки могут быть агрегированные позиции — для точной сметы разбивайте по кодам ФССЦ.
5. **Сайт требует авторизации** для некоторых функций, но базовые страницы расценок открыты.
