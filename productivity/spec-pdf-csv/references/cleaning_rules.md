# Правила очистки текстов (ссылочный файл)

> Содержит ДЕТАЛИЗАЦИЮ правил п.5 SKILL.md.
> Не читать целиком — только при возникновении артефактов в stage2.

## Разорванные слова (SPLITS)

Список пар (испорчено → правильно) в `extract_spec.py`. Расширяется под документ.

Типичные: `Труб а→Труба`, `электрос варная→электросварная`, 
`оцинков анная→оцинкованная`, `К ов ер→Ковёр`, `Трой ник→Тройник`,
`Патруб ок→Патрубок`, `Ги б кая→Гибкая`, `Д р о с с е л ь→Дроссель`.

**Алгоритм**: после очистки проверить stage2 — если есть одиночные буквы
(токены длиной 1 из `[а-яёА-ЯЁ]`) — найти цепочку, добавить в SPLITS,
перезапустить.

## Артефакт Ø (ToUnicode шрифта)

Правило токенов:
- `6` + след.токен ∈ DIAMETERS → `Ø<токен>` (для ВК)
- `6<диаметр>х<толщина<100>` → `Ø<диаметр>х<толщина>` (труба ВК)
- `ф<цифры>` → `Ø<цифры>` (для ОВ)
- `∅` → `Ø`
- **НЕ трогать** `DN...`, `Ду=...`, `Д=...`, `650x400` (размер воздуховода)

## Склейка ГОСТ/ТУ-номеров

`ТУ -2248- 043- 00284581-2000` → `ТУ-2248-043-00284581-2000`

Правило: `(ТУ|ГОСТ)\s+-\s+` и `(-)\s+(\d)` → без пробелов.

## В1 .3 → В1.3

Пробел перед дробью в обозначениях: `(\d)\s+(\.\d)` → `\1\2`

## Ведущий дефис

`- кран шаровой Ду20` → `кран шаровой Ду20` (маркер вложенности, не часть имени).
Иначе Excel читает как формулу → `#ИМЯ?`.

## Позиции — нумерация строго по исходнику

Номер позиции (Поз.) берётся из PDF **как есть**. Запрещено:
- перенумеровывать последовательно,
- «чинить» дубликаты или пропуски,
- сдвигать номера после удаления/добавления строк.

**Дубликаты номеров — легитимны.** В исходных спецификациях встречаются
повторяющиеся позиции (напр., две строки №22 в К1, ВК2.3) и пропуски нумерации.
Это дефект/особенность оригинала — отражается 1:1. Если пользователь не просит
исправить нумерацию — не исправлять.

## Поставщики с артефактами

`Ekopl astik→Ekoplastik`, `Агпа йп→Агпайп`

## НЕ склеивать

- Пробел перед дефисом: `Bazaltek euro -ШБТ-10` (пробел настоящий)
- Пробелы в количестве: `1 295` — разделитель тысяч, оригинал
