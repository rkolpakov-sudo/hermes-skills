# Vision misreads — систематические ошибки vision-извлечения

При извлечении данных через `vision_analyze` модель систематически misread'ит некоторые глифы.
Этот файл — живой справочник; дополнять по мере обнаружения новых паттернов.

## Диаметр круглых воздуховодов
**Проблема:** vision читает символ диаметра в разных регистрах/скриптах: `Φ` (греч.), `Ф` (кирилл.), `ф` (кирилл. строчная), `∅` (U+2205).
**Нормализация:** только `ф/Ф/Φ + цифры → ∅ + цифры` — НЕ blanket-транслитерация (не тронуть ФОК, Фл, ФВ).
**Regex:** `r'(^|\s)([фФΦ])\s?(\d+(?:[.,]?\d+)?)' → r'\1∅\3'`

## Смешанные алфавиты (Cyrillic/Latin)
| Что читает vision | Должно быть | Частота | Причина |
|---|---|---|---|
| `КVК` | `КВК` | системно | V vs B в italic |
| `UPRR-*` (R) | `UPRP-*` (P) | системно | P vs R в рукоп. |
| `Velim` (V) | `Belimo` (B) | 2×/документ | V vs B |

## Искажённые цифры
| Что читает vision | Должно быть | Где | Причина |
|---|---|---|---|
| `З/` (буква З) | `3/` (цифра 3) | типы КЦ35С (З/3000) etc | кирилл. З vs 3 |
| `(I20)` | `(120)` | пределы огнест. | I vs 1 |
| `EI50` (без 1) | `EI150` или EI15 | примечания к воздуховодам | потеря «1»; проверять по coating+арифметике |

## Буквы в кодах оборудования
| Что читает vision | Должно быть | Где |
|---|---|---|
| `KOL-` | `KOV-` | обратный клапан (italic L vs V) |
| `Е160` | `EI60` | пределы огнестойко |
| `Е130` | `EI30` | примечания |
| `BPD` / `РД` | `PD` | код вентилятора VR-80-75-XPD |
| `E6.4` / `EG.4` / `ЕВ.4` | `G4` | класс фильтра |
| `E7.7` / `EF.7` | `F7` | класс фильтра |
| `Изовент` / `Изоvent` / `Изовернт` | `Изоверт` | мат-л покрытия |
| `Оgneзащитное` | `Огнезащитное` | смешан. скрипт |

## Размеры без наследования (мать-ребёнок)
**Проблема:** vision пишет круглый размер строчной `ф` (`ф125`), который не совпадает с `SIZE_RE` (содержит `ΦФ∅Ø`).
**Решение:** DEFAULT_SIZE_RE должен включать все варианты:
```
SIZE_RE = re.compile(r'^[фФΦ∅Ø]s?\d+|^\d{2,5}[хxХ]\d{2,5}|^\d{2,5}[хxХ]\d{2,5}/\d{2,5}[хxХ]\d{2,5}')
```

## Pattern A — ложное срабатывание на загловках
**Проблема:** `CONT_RE` матчит прописную «С» в «Системы ПДЗ...» → merge с предыдущей строкой.
**Решение:** `CONT_RE` должеn включать только СТРОЧНУЮ:
```
CONT_RE = re.compile(r'^[а-яa-z0-9()/]|^(с |и |220|3/)')  # НЕ [А-Я]
```
