# Правила классификации строк (ссылочный файл)

> ДЕТАЛИЗАЦИЯ правил п.4–4a SKILL.md.
> Читать при неверной классификации в stage3_rows.

## 1. Базовые роли

| Условие | Роль | Пример |
|---------|------|--------|
| есть qty (кол-во) | **item** | Труба стальная 25×3,2 — qty=125 |
| без qty + заголовок раздела | **header** | «Трубы и изоляция», «Оборудование» |
| без qty + есть type (ГОСТ/ТУ/марка) | **component** | «состав комплекта: а) клапан…» |
| без qty + нет type | **continuation** → MERGE с предыдущей | «∅100» после «Труба стальная» |
| пустое имя + type + qty | **group_inherit** — наследует имя предыдущей | ∅100 (пустое имя) после «Воздуховоды» |

## 2. Заголовки разделов (header)

Распознаются по `HEADER_PREFIXES` (22 префикса) или `HEADER_RE`.

**Критично**: если раздел не попал в список → приклеится к предыдущей позиции
(«Грунтовка ГФ-021 Горячее водоснабжение»).

## 3. Подзаголовки установок (НЕ матери)

Строки вида `1-П1`, `1-В2`, `1-КДУ2`, `1-ДУ1`, `1-ПД3` — структурные
подзаголовки в ОВ-спецификациях. Их роль — **не header, не mother, не item**.
В текущей реализации классифицируются как `item` с пустым qty — это OK
(они попадут в items_no_qty как сигнал к проверке).

## 4. Правило 4a — MOTHER_ABSORBED (НЕ РЕАЛИЗОВАНО В СКРИПТЕ)

Материнская строка (полное описание БЕЗ количества) НЕ выдаётся отдельно —
поглощается дочерними позициями.

**Когда применяется**: строка с name+type, БЕЗ qty, с детьми (строки ниже с qty).
Пример: «Воздуховоды из листовой оцинкованной стали толщиной 0,8мм» ГОСТ 14918-80
→ дети ∅100 (м,20), ∅125 (м,30).

**Правила детей**:
- ребёнок с пустым name: name := имя матери, type := свой типоразмер
- ребёнок с коротким обозначением (нет кириллицы ≥3 букв, длина ≤45):
  name := имя матери, его обозначение → в type, код/поставщик/примечание
  наследуются от матери если пусто
- мать С количеством («Труба медная») — остаётся item И открывает группу
- структурные подзаголовки (`1-П1`, двоеточие в конце) — НЕ матери

**Лог**: MOTHER_ABSORBED / FULL_NAME_CHILD / FULL_NAME_INHERIT

## 5. Дефисные строки

`- КТР-20`, `- дюбель-втулка`, `- грунтовка` — самостоятельные позиции
состава группы. НЕ продолжения, НЕ наследуют имя матери. Ведущий дефис
убирается в clean_name (маркер вложенности).
